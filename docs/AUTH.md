# Регистрация и доступ

## Роли

| Роль | Как получить |
|------|----------------|
| **Главный администратор (учредитель)** | `is_owner=1`, создаётся через env или `setup-founder.js` |
| **Администратор (учредитель)** | Регистрация в приложении → одобрение главным админом |
| **Водитель** | Админ создаёт в «Водители» или самoregистрация с кодом приглашения |

## Главный администратор

При первом запуске сервер создаёт учредителя, если email ещё не занят:

```env
FOUNDER_ADMIN_EMAIL=ваш-email@mail.ru
FOUNDER_ADMIN_PASSWORD=надёжный-пароль
FOUNDER_ADMIN_FULL_NAME=Иван Иванов
```

Или вручную на уже работающем сервере:

```bash
cd server
FOUNDER_ADMIN_EMAIL=ваш@mail.ru FOUNDER_ADMIN_PASSWORD=secret node scripts/setup-founder.js
```

Скрипт создаст аккаунт или обновит существующий (роль admin, `is_owner=1`, восстановление пароля включено).

## Регистрация нового учредителя

1. На экране входа → **Регистрация** → роль **Учредитель**
2. Email, пароль, повтор пароля, ФИО
3. Заявка попадает в очередь `admin_registration_requests`
4. **Главному администратору** приходит уведомление
5. **Ещё → Заявки учредителей** (или **Уведомления → Одобрить**)
6. После одобрения учредитель входит как admin; **восстановление пароля** доступно без кода

Одобрять и отклонять заявки может только пользователь с `is_owner=1`.

## Регистрация водителя

**Способ A (рекомендуется):** админ → **Ещё → Водители → Создать** → передать email и пароль.

**Способ B:** самoregистрация с кодом `REGISTRATION_INVITE_CODE` (если задан на сервере).

После создания/регистрации у водителя `password_reset_enabled=1` — сброс пароля на экране «Забыли пароль?» **без кода**.

## Восстановление пароля

| Аккаунт | Когда доступен сброс без кода |
|---------|-------------------------------|
| Учредитель после одобрения | Да |
| Водитель (создан админом или зарегистрирован) | Да |
| Старые аккаунты без флага | Нужен `PASSWORD_RESET_CODE` с сервера |

## API

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/api/auth/register` | `role: admin` → заявка; `role: driver` → сразу вход |
| GET | `/api/admin-registrations` | Список заявок (admin) |
| POST | `/api/admin-registrations/:id/approve` | Одобрить (только owner) |
| POST | `/api/admin-registrations/:id/reject` | Отклонить (только owner) |
| POST | `/api/auth/forgot-password` | Сброс пароля |
